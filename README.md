## "Двойник" КА

Это консольное приложение scTwin, которое представляет систему управления базой конфигураций КА. Как минимум при запуске "двойника" в консоли должен быть 1 параметр - номер конфигурации КА. Все конфигурации записаны в файле twBase.json.
Основные функции:
1. Выбор нужной конфигурации из базы (twBase.json)
2. Копирование файла с описанием БС КА и его свойств в папку сonfigInOut. Этот файл относительно scTwin находится в папке ./scConfig/out42/SC_<имя_конфигурации>.txt (для СУД) и SPS_<имя_конфигурации>.txt для СЭП.
3. Копирование файла орбиты в папку сonfigInOut. Относительно scTwin он находится в orbConfig и имеет имя Orb_<имя_аппарата>.txt.
4. Изменять файл ../42support/CMakeLists.txt в зависимости от версии БПО. Версии БПО находятся в папке swConfig.
5. Собирать программу моделирования функционирования КА "Проект 42"
6. Запускать собранный "Проект 42", при этом папка исходных данных (ИД) назначается configInOut.
7. В папке configInOut уже лежит файл с ИД сценария моделирования (по-умолчанию) Inp_Sim.txt и пустой файл команд Inp_Cmd.txt.

По результатам запуска "Проект 42" должен сформировать значения основных показателей работы КА по заданному сценарию. При этом scTwin на основе этих значений должен сформировать обобщённый показатель и занести его в базу конфигураций.

Сборка scTwin стандартными средствами Qt, ЯП - ANSI C, файл проекта scTwin.pro

## Конфигуратор БС КА

Основная цель консольного приложения scConfig/configs сформировать из файла конфигурации БС (<имя_системы>/<имя_конфигурации>.json) входной файл для "Проекта 42" (out42/SC_<имя_конфигурации>.txt для СУД и out42/SPS_<имя_конфигурации> для СЭП). 
При этом в файле конфигурации записаны только названия типовых приборов и их кол-во, описание приборов находится в соответствующих файлах - <имя_системы>/dev/<тип_прибора>.json
Основные функции:
1. По входному аргументу определить необходимый файл <имя_системы>/<имя_конфигурации>.json
2. На основе шаблонов out42/SC_Template.txt (для СУД) и out42/SPS_Template.txt (для СЭП) создаём новый файл out42/SC_<имя_конфигурации>.txt (out42/SPS_<имя_конфигурации>) в соответствии с файлом <имя_системы>/<имя_конфигурации>.json

Сборка configs стандартными средствами Qt, ЯП - ANSI C, файл проекта scConfig/configs.pro
